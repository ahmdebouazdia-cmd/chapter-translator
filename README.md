# مترجم الفصول

تطبيق أندرويد مفتوح المصدر (ترخيص MIT) لترجمة الفصول بالذكاء الاصطناعي، مبني بـ HTML/JS داخل غلاف [Capacitor](https://capacitorjs.com).

## المزايا
- ترجمة فصول كاملة بأي لغة إلى 15 لغة، مع تقسيم تلقائي للفصول الطويلة
- تغيير صيغة السرد (ضمير الغائب / المتكلم) وتغيير أسماء الشخصيات
- تلوين جمل الحوار، وخيارات للخط والحجم والمظهر
- تعديل ذكي للترجمة، ومساعد للدردشة عن الفصل
- مكتبة للفصول المحفوظة، وتنزيل/مشاركة بصيغة HTML أو TXT

## أولًا: مفتاح API
التطبيق يتصل بواجهة Anthropic باستخدام **مفتاحك الخاص**. أنشئ مفتاحًا من console.anthropic.com، وأدخله لاحقًا في تبويب «الإعدادات» داخل التطبيق. يُحفظ المفتاح على جهازك فقط، وكل ترجمة تُحتسب على حسابك.

## بناء ملف APK بدون تثبيت أي شيء (GitHub Actions)
1. أنشئ حسابًا مجانيًا على github.com ثم مستودعًا جديدًا (New repository).
2. ارفع محتويات هذا المجلد إلى المستودع (Add file ← Upload files). المجلدات المخفية قد لا تُرفع من الجوال، فإن لم يظهر `.github` فأنشئ الملف يدويًا: Add file ← Create new file، واكتب الاسم `.github/workflows/build-apk.yml` والصق محتواه.
3. افتح تبويب **Actions** ← **Build APK** ← **Run workflow**.
4. بعد دقائق افتح التشغيل المكتمل ونزّل الملف المضغوط **chapter-translator-apk** من قسم Artifacts، وفك الضغط لتحصل على `app-debug.apk`.
5. ثبّت الملف على جوالك (قد تحتاج السماح بالتثبيت من مصدر غير معروف).

## البناء على حاسوبك
يلزم Node 20 وJDK 17 وAndroid SDK:

```bash
npm install
npx cap add android
npx cap sync android
cd android && ./gradlew assembleDebug
# الناتج: android/app/build/outputs/apk/debug/app-debug.apk
```

## استخدام مزوّد آخر
كل الاتصال بالنموذج في دالة واحدة اسمها `callModel` داخل `www/index.html`. استبدل عنوان الطلب والترويسات وشكل الجسم وتحليل البث فيها لتناسب مزوّدك، وستعمل بقية الواجهة كما هي.

## ملاحظات
- الملف الناتج «debug» موقَّع بمفتاح اختبار، وهو مناسب للاستخدام الشخصي. للنشر في المتاجر تحتاج بناء إصدار release بمفتاح توقيعك.
- الخطوط تُحمَّل من Google Fonts، وبدون إنترنت تُستخدم خطوط النظام.
- لتغيير الأيقونة يمكنك استخدام `@capacitor/assets`.
